Mode for the next interactive launch

Saving records your choice only. It does not restart the server, change Windows networking, or connect other devices.

Apply it on the server computer

  1. Finish any active attendance sessions, then stop the server.
  2. On the computer running this installation, reopen START_HERE.cmd from the same installed folder.
  3. Select the mode button you want in the setup window. For Shared LAN, follow the guided Windows network, certificate-trust, and firewall approvals. Closing the window starts nothing.

You may be viewing this page from another laptop. These launch steps must be performed on the server computer.

Automatic startup is a separate setting

This saved choice applies only when someone opens the interactive START_HERE.cmd menu. It does not change a scheduled LAN task.

If you are switching to Local only, use the automatic-startup manager on the server computer to Stop and Disable any existing LAN task. Saving Local only here does not disable it.

The server must stay powered on and awake. The connection kit does not contain the application database or create user accounts.

The guided installer and connection kit currently support Windows. Setup on macOS, Linux, phones, and tablets has not yet been validated.

If another laptop cannot connect

A changed server address, a different router, or an old connection kit can prevent access. Ask the system owner or technician to check the server's LAN configuration and provide a freshly verified kit.

Do not bypass certificate warnings. You can choose Local only and reopen this installation on the server while LAN setup is repaired. If a scheduled LAN task exists, stop and disable it separately.
