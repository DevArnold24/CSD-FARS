How to connect the system
  1. Connect the server, cameras and browser laptops to the same intended router or switch network.
  2. Use Setup Center to choose shared access and follow setup on the server. Reserve its address in your router so the connection kit stays valid.
  3. Give each joining laptop the server's browser connection kit, then sign in with an account from this server.

A Dean manages sharing. Windows address, certificate and firewall changes are completed on the server through setup. Switch ports and power capacity require the switch's own management tools.

Using Wi-Fi internet and a camera LAN together

Wi-Fi internet and a wired camera connection can work at the same time. Windows chooses the route for camera video. The adapter selected during camera search only limits discovery; it does not select the connection used for saved-camera video or attendance.

If a camera works only after Wi-Fi is disconnected, ask the installer to check the server's adapter address ranges and routes. Separate networks with overlapping IPv4 ranges may need distinct address ranges or an appropriate route. Changing adapter priority alone may disrupt internet access and may not resolve the overlap.

This page compares reported adapter addresses only. It does not test a camera, identify its selected route, or change Wi-Fi, routes or firewall settings.

What do the device states mean?

Reachable: Windows recently confirmed reachability. Stale: a remembered address without recent confirmation. Delay / Probe: Windows is checking. Incomplete / Unreachable: address resolution or reachability is not established. Permanent: a fixed entry; this does not confirm a live device.

For the router's full lease list or a managed switch's ports, use its own device view. CSD does not currently read those management systems.
