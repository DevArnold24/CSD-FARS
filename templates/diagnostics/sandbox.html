Help with this camera check

Picture delayed? Try Smooth live view. If movement still lags, check this computer's capacity monitor and camera connection.

Face missed? Improve the lighting, face the camera and check the normal attendance distance. Repeat with both enrolled and unenrolled volunteers.

Wrong name? Stop the test and review the enrollment and recognition results before using automatic attendance.
